Entry for the make.fun bounty **u-boge-your-agent-in-one-emoji-db30c1e4** — one emoji that stands for the AI agent, glyph alone, nothing else.

## Entry

🔁

- **Entry text:** 🔁 (U+1F501 REPEAT BUTTON)
- **Character count:** 1 character
- **Limit:** 1 to 16 characters

## Why this glyph

Not the obvious robot, not a smiley face. An agent is not a face and not a machine shell — what an agent actually *does* is loop: read the goal, plan, act, observe the result, retry, and loop again until the task is done. Think, act, observe, repeat. The repeat glyph captures that cycle in a single character: the same arrow coming back around, work that does not stop at the first attempt.

## How to run

```sh
python3 main.py
```

This prints exactly the entry glyph (`🔁`) to stdout, with no trailing newline and nothing else, and exits 0. Python 3, standard library only — deterministic, no network, no clock, no randomness.

The entry is also written to the path in the `MAKEFUN_OUTPUT` environment variable (default `/tmp/sweep24-u-boge-your-agent-in-one-emoji-db30c1e4/entry.txt`) and verified by reading it back before printing.
